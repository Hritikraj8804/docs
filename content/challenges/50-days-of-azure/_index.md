The **#50DaysOfAzure** challenge is a hands-on learning track designed to master Azure cloud infrastructure and SRE practices using the KodeKloud Engineer platform. By completing daily tasks, I gained comprehensive experience managing Azure resources and automating administrative workflows.

### 🎯 Learning Objectives
- **Azure Administration**: Configuring and managing Virtual Machines, Virtual Networks, and Active Directory.
- **Resource Automation**: Provisioning infrastructure using Azure Resource Manager (ARM) templates and Azure CLI.
- **Security & Networking**: Setting up Network Security Groups (NSGs), Application Gateways, and private endpoints.
- **Storage & Databases**: Implementing Blob Storage, Azure Files, and configuring Azure SQL Databases.

### 🛠️ Core Topics Explored
- **Compute**: Azure Virtual Machines, VM Scale Sets, and App Services.
- **Networking**: VNet, Subnets, VPN Gateways, Load Balancers, and DNS zones.
- **Security & Identity**: Azure Active Directory (Microsoft Entra ID), RBAC, Key Vaults, and IAM.
- **Diagnostics & Monitoring**: Azure Monitor, Log Analytics, and Alerts.
